INWO Card List Generator

N.B. This is Ralph's slightly hacked copy of Wendell Hickens' INWO Card List Generator. All credit should go to him. I, Ralph, should check back there from time to time to see if anything has changed.

Filter: Enter a string or expression to limit which cards are displayed.


Expansions to Include:
Default is all expansions. Options are:
  • O Original (limited/unlimited)
  • A Assassins

Display Fields:
Default is NTPRLSD_. Options are:

  • A artist
  • C commonality
  • D description
  • E expansion
  • L alignment
  • N name
  • O # of outgoing arrows
  • P power
  • Q requirements
  • R resistance
  • S attributes
  • T type (e.g. Resource)
  • # # of alignments
  • + - plus, enables HTML tables
  • _ - underbar, draw horizontal lines
  • [ - left bracket, draw small "check boxes"
You can also control the output using the formatting options.

Sort order:
Default is CN. Options are:

  • A artist
  • C commonality
  • E expansion
  • G global power
  • L alignment (only as first sort key)
  • N name
  • O # of outgoing arrows
  • P power
  • R resistance
  • S attributes (only as first sort key)
  • T type (e.g. Resource)
  • # # of alignments
